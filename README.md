# 🏨 Hotel Booking & Cancellation Analysis – Excel Dashboard

## 📌 Project Overview

This project focuses on analyzing hotel booking data and identifying booking and cancellation trends using Microsoft Excel.

An interactive dashboard was developed to transform raw hotel booking data into meaningful business insights. It helps analyze hotel performance, guest categories, room status, and monthly booking trends.

## 📂 Dataset

- **Dataset:** [Hotel Booking Dataset](https://github.com/amitgupta654312-alt/Data-Analysis-Dashboard/blob/main/hotel%20data.xlsx)
- **Total Records:** 119,390
- **Hotel Types:** City Hotel and Resort Hotel
- **Time Period:** 2015–2017

## 🎯 Business Questions (KPIs)

The dashboard answers the following business questions:

1. What is the total number of hotel bookings?
2. What is the total number of cancelled bookings?
3. What is the distribution of bookings between City Hotel and Resort Hotel?
4. How many bookings are cancelled in City Hotel and Resort Hotel?
5. Which guest type has the highest number of bookings?
6. How many bookings are cancelled for each guest type?
7. How many bookings have Desired and Undesired room status?
8. How many cancellations are associated with each room status?
9. How do total guests and cancelled bookings change month by month?
10. How do booking and cancellation figures change when selecting different years?

## 🛠️ Tools & Technologies

- Microsoft Excel

- Pivot Charts
- Slicers

## 📊 Dashboard Features

- KPI cards displaying total bookings and total cancellations.
- Hotel-wise booking distribution analysis.
- Hotel-wise cancellation distribution.
- Guest type analysis (Couples, Family, and Single).
- Room status analysis (Desired and Undesired).
- Monthly booking and cancellation trend analysis.
- Interactive year-wise filtering using Excel Slicers.
