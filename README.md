# Data-Analysis-Dashboard
An interactive Excel dashboard project designed to analyze hotel booking data and cancellation trends. This project provides insights into total bookings, cancellations, hotel types, guest categories, room status, and monthly booking performance.
# Dataset used
- <a href="https://github.com/amitgupta654312-alt/Data-Analysis-Dashboard/blob/main/hotel%20data.xlsx">Dataset</a>

## Questions (KPIs)
-	What is the total number of hotel bookings?
-	What is the total number of cancelled bookings?	
-	What is the distribution of bookings between City Hotel and Resort Hotel?
-	How many bookings are cancelled in City Hotel and Resort Hotel?
-	Which guest type has the highest number of bookings?
-	How many bookings are cancelled for each guest type?
-	How many bookings have Desired and Undesired room status?
-	How many cancellations are associated with each room status?
-	How do total guests and cancelled bookings change month by month?	
-	How do booking and cancellation figures change when selecting different years?
